Deskripsi Riset

Penelitian ini berfokus pada optimisasi model machine learning untuk klasifikasi citra medis, dengan tingkat akurasi mencapai 95% pada dataset uji. Proses pelatihan model menggunakan parameter β (beta) sebagai koefisien regulasi dan μ (mu) sebagai nilai rata-rata distribusi data — keduanya dioptimalkan melalui teknik hyperparameter tuning. Hasil riset ini telah dipublikasikan pada jurnal internasional bereputasi dan mendapatkan sitasi dari berbagai peneliti di bidang terkait. © 2024 Program Studi Teknik Informatika, Universitas Brawijaya.
